# Pokémon Type Matchup Analyzer

A modern, responsive web application for analyzing Pokémon type effectiveness (Gen VI+). It features interactive dual polygon radar charts (Defense & Attack) built with Vanilla JavaScript and Canvas API.

## Features
- **Dual Radar Charts**: Visually compare Defensive (Damage Taken) and Offensive (Damage Dealt) capabilities.
- **Dual Type Support**: Select Primary and optionally Secondary types.
- **Fully Responsive**: Optimized for Desktop, Tablet, and Mobile views.
- **Interactive UI**: Glassmorphism aesthetic, hover tooltips, smooth animations.

## Tech Stack
- Vanilla JavaScript (ESM)
- HTML5 Canvas API
- Vanilla CSS3 (Custom Properties, Grid, Flexbox)
- Vite for fast local development

## Getting Started

1. Install dependencies:
   ```bash
   bun install
   ```

2. Run the development server:
   ```bash
   bun run dev
   ```

3. Open `http://localhost:5173` in your browser.

## Build for Production
To bundle the application for production deployment:
```bash
bun run build
```
